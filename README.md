informação sobre o code

- este código usa muitas funções de return de estado, ous eja as variaveis para substituir vem em preferencias nos parametros e elas só retornam o estado da unção, sucesso, erro, outro estado.

- Os menus funcionam em forma de árvore, ou seja começamos com o primeiro menu(main menu) e vamso descendo para o menu de jogadores ou menu de jogos.


- para entrar em um jogo o processo é: menu de jogador -> selcionar jogador -> voltar -> menu princiapal -> menu jogos -> engine -> processo principal do jogo.
