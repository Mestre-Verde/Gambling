# Ficheiros

Um ficheiros é uma sequencia de bytes.

Um ficheiro pode ser:
    - uma fonte(config)
    - uma saida(log)
    - Uma fonte e saida (tmp)
  
Perifiericos:
    - IN (teclados, ratos)
    - OUT (display, impressora)
    - IN/OUT (qualquer dispositivo de armazenamento)
  
C processa qualquer tipo de periférico como uma __steam__.

Uma Steam é um conjunto de bytes que pode correpsonder a um ficheiro ou periférico.
